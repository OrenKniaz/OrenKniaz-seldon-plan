3. Five focused design changes (savings above overlap; do not add every maximum)
1) Make the guide's execution contract match a real walkthrough. Distinguish URL links, delivered paths and sample/generated files; validate all format issues together before integration. Use one ordinary terminating walkthrough check that creates fixtures, starts the documented command, waits for readiness, exercises the real interaction and cleans up. Keep state within that check, not across disposable observations. Human launch examples remain readable; verification must execute the same documented operations. Files: guide.py, plan.py, questions.py, wave_verify.py. Expected 13–27 min. Risk: an independent “green script” drifting from the guide; bind its inputs to the delivered guide and retain browser evidence. Do not shorten deadlines or count timeout as success.
2) Route each gap to its actual correction owner and supply the evidence appropriate to that repair. Let the semantic verdict name the responsible approved unit/contract; code validates it instead of equating all traced contributors with writers. Keep coverage/invalidation separate. Supply valid historical RED with its original commit and the current failing gap to fixup judges; new behavior still needs appropriate RED, and integrated GREEN still runs on the new commit. Resolve a required shared literal through the existing contract owner once. Files: flow_review.py, schema.py, fixups.py, units.py, questions.py. Expected 15–25 min in g04; much less in clean runs. Risk: under-routing a cross-owner defect or stale evidence; preserve explicit multi-owner corrections, Git identities and final real-path proof. A stronger prompt alone will not fix the owning data boundary.
3) Plan one owner for the integrated delivery scenario and one for user documentation; avoid commissioning overlapping importer and delivery harnesses plus a separate rediscovery guide. Keep every distinct obligation (fresh folder, keyboard, offline, restart, errors), assigning it once at its strongest boundary. Contract consumption/writing a future wave check must not itself create a dependency on UI files; actual local reads still require one. Files: architecture.py, detail.py, plan.py, questions.py; scheduler.py need not change. Expected 8–14 min on an h02-shaped plan. Risk: lost integration coverage or undeclared reads; prove the real canonical producer→consumer path and compare requirement coverage. Keep the cohesive UI unit initially; splitting its 10–15 min can add an integrator and more rework.
4) Use the existing role table for task-appropriate model/effort, passing explicit task context through both deadline selection and provider.prepare. Trial Terra 6.1/medium for bounded docs, small workers, narrow contract corrections and reviews; trial medium for suitable Sol workers. Retain strong architecture, complex workers and unit judgment; only trial narrower semantic verdicts with unchanged evidence and measured agreement. Files: providers.py, questions.py, inference.py. Expected 3–6 additional min; Terra's speed/quality advantage is not established by these traces. Risk: more retries or weaker craft cancel gains. ALIGN is already medium, JUDGE medium, FLOW/PRODUCT high: don't claim all roles are high or blindly upgrade JUDGE to high. R13 currently says strongest planning/judgment; broader Terra ALIGN/judgment routing requires Oren's explicit policy resolution, not a silent downgrade.
5) Fan out independent FLOW subjects on one frozen candidate, then independent PRODUCT subjects, using existing capacity and one deterministic writer to apply all verdicts/gaps. Preserve one typed question per subject, resumability, uncertainty and unanimous required closure. Files: flow_review.py, judgment.py, inference.py. Expected 3–4 min. Risk: stale replies or parallel gaps changing the candidate; apply replies only to their original commit and do not mutate mid-batch. Do not combine everything into one giant model call.
Together these suggest roughly 25–35 min for g01/h02-shaped runs and 30–45 for a g04-shaped run if repairs converge. These are hypotheses, not a measured 30-minute result.
