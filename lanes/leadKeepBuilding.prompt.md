## Design
A WORK return that says the work is not done (no candidate, or a candidate that does not cover the milestone, with a "next step") is the builder stopping early. It is not a failure for the person. Seldon resumes the SAME builder session (the existing resume path) with: the builder's own next step quoted, the milestone's B promises, and "continue until every promise of this milestone is built and checked; return only when done or truly blocked". Repeat while each return shows progress (changed files or a new candidate). Escalate only on a true block: a decision only the owner can make, missing access or equipment, or repeated returns with no progress (route that to the planner first, then the person with options + Other). Never cap; measure. Delete the routing that sends "not done yet" to the person. Net production lines should not grow. Switch: SELDON_OFF=leadKeepBuilding.
